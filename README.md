# Scheduly - Aplikasi Manajemen Jadwal & Catatan Tim

Scheduly adalah aplikasi web modern berbasis cloud untuk mengelola jadwal shift operasional tim, pramuniaga, kasir, dan jadwal umum secara real-time.

## 🚀 Fitur Utama Terbaru: Drag and Drop Pertukaran Shift
* **Pertukaran Shift Langsung:** Admin kini dapat dengan mudah menyeret (drag) sel shift dari satu staf/tanggal dan melepaskannya (drop) ke sel staf/tanggal lainnya.
* **Tanpa Pop-Up Tambahan:** Proses pertukaran jadwal antar sel dapat dilakukan secara instan tanpa harus membuka pop-up pilihan shift, sehingga mempercepat efisiensi manajemen jadwal.
* **Keamanan Hak Akses:** Fitur seret dan lepas ini dilindungi oleh hak akses khusus Admin untuk menjaga validitas data jadwal tim.

## 🛠️ Fitur Lainnya
* **Sinkronisasi Cloud Real-time:** Terhubung langsung dengan Firebase Real-time Database untuk pembaruan data antar perangkat.
* **Manajemen Sesi & Peran:** Pengaturan hak akses bertingkat antara Admin dan Anggota Tim (Member).
* **Log Aktivitas & Request Jadwal:** Pencatatan otomatis setiap tindakan serta fitur persetujuan request jadwal oleh anggota.
* **Folder Penyimpanan & Draft:** Pengelolaan arsip bulanan, multi-pilih item, sub-folder, serta penyimpanan draft lembar kerja.
* **Ekspor Laporan Bersih:** Mendukung ekspor ke format Excel (.xls), Word (.docx), PDF, dan CSV yang otomatis menyaring dokumen agar hanya menampilkan tabel jadwal dan catatan penting.
