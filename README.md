🌟 Fitur Utama Terbaru & Unggulan
 * 🔄 Pertukaran Shift Seret & Lepas (Drag & Drop): Admin kini dapat dengan mudah menyeret (drag) sel shift dari satu staf/tanggal dan melepaskannya (drop) ke sel tujuan secara instan tanpa perlu membuka pop-up pilihan shift.
 * ☁️ Sinkronisasi Cloud Real-time: Terhubung langsung dengan Firebase Real-time Database untuk memastikan pembaruan data antar perangkat berjalan tanpa jeda.
 * 👑 Manajemen Sesi & Peran Akses: Pengaturan peran bertingkat antara Admin (akses penuh kelola jadwal, staf, dan persetujuan request) dan Anggota Tim / Member (melihat jadwal & mengajukan request shift mandiri).
 * 📋 Log Aktivitas & Request Jadwal: Pencatatan otomatis setiap tindakan serta fitur persetujuan (approve/reject) request shift dari anggota tim.
 * 📁 Folder & Penyimpanan Draft: Pengelolaan direktori multi-folder, sub-folder, penyimpanan sesi aktif sebagai draft bulanan, hingga fitur multi-pilih item untuk arsip yang rapi.
 * 📊 Deteksi Hari Libur & Kalender Hijriah: Deteksi otomatis hari libur nasional serta hari besar Islam (Hijriah) pada tabel bulanan.
 * 📤 Ekspor Laporan Bersih: Mendukung ekspor ke format Excel (.xls), Word (.docx), PDF (.pdf), dan CSV (.csv) yang otomatis menyaring dokumen agar hanya menampilkan tabel jadwal dan catatan penting.
🚀 Panduan Cepat Penggunaan (Quick Start)
1️⃣ Pembuatan Akun & Masuk (Login)
 * 👑 Akun Admin: Pilih tab Masuk (Login) atau Daftar Anggota Baru, pilih peran Admin, masukkan nama konter serta PIN server rahasia Anda untuk mulai mengelola lembar kerja.
 * 👥 Akun Anggota (Member): Pilih tab Daftar Anggota Baru, masukkan Nama Konter dan PIN Server yang sama dengan Admin Anda, pilih proyek Admin terkait, lalu masukkan nama lengkap Anda untuk melihat jadwal dan mengajukan request.
2️⃣ Pertukaran Shift Cepat (Drag & Drop)
 * Klik dan tahan (drag) pada sel jadwal shift staf yang ingin dipindahkan.
 * Seret kursor ke sel tujuan (bisa antar tanggal berbeda atau antar staf berbeda).
 * Lepaskan (drop) klik pada sel tujuan. Shift kedua sel tersebut akan otomatis saling bertukar atau terpindah dengan aman.
3️⃣ Pengelolaan Arsip & Folder
 * Buka menu Folder Penyimpanan untuk mengelola direktori utama, membuat sub-folder, atau menyimpan sesi aktif lembar kerja sebagai draft bulanan.
 * Gunakan fitur Multi-Pilih untuk memindah, menyalin, atau menghapus beberapa file dan folder arsip sekaligus.
